# paper-agent

A local-first, evidence-grounded workspace for deep reading AI/ML papers.

The project is being delivered in four independently testable increments:

1. Parsing and persistence
2. Evidence-backed paper knowledge graph
3. Agent runtime with citation guard
4. Three-pane web UI

The accepted design is in `docs/superpowers/specs/2026-08-08-paper-agent-design.md`.

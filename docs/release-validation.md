## 审查与隔离

独立只读审查未发现本轮可确认缺陷，重点核对数据库提交后的补偿边界、独立笔记锚点和 E2E 数据隔离。服务器仅替换模型传输，使用生产解析、服务、数据库与模型回答解析。数据在独立系统临时目录，正常退出清理；每个浏览器用例仅删除自己上传的论文。测试未使用私人 PDF、真实模型或浏览器登录。

README 截图为合成数据，已人工查看桌面与小屏截图。未纳入环境 `AGENTS.md`、虚拟环境、运行数据库、用户论文、浏览器缓存或测试报告。旧计划中的凭证文本已移除，但 Git 历史未重写，也未执行远程推送；凭证持有者应更换仍有效的凭证。

## 仍需注意

- 后端新环境有一条 Starlette/AnyIO 的弃用警告，未造成失败；前端构建仍提示大包体积。
- npm 提示 MSW 安装脚本待批准；本轮没有扩大脚本授权，测试与构建均正常。
- Python 依赖为版本范围，不是全量锁定文件；上述结果证明本次新安装可用，不保证未来解析到不同依赖版本时永远一致。
- 真实 vLLM、扫描件 OCR、跨页选区、多用户和云同步不属于本次验收。自动化可访问性检查不能替代完整人工辅助技术测试。
- 测试服务只监听本机且拒绝复用已有端口。受限环境中曾出现下载/进程收尾停滞，获准在非受限环境运行后完成；强制结束可能留下系统临时数据。
